# Mini Program website sync

Treat the current Mini Program source as authoritative. Sync project order, filters, cover assets, alt text, and editorial source notes together; verify copied image hashes and field values before publishing.

For responsive images in generated markup or canvas scenes, derive priority selectors from the emitted DOM and keep a one-time original-source fallback. Verify with a fixture that includes preceding decorative images.

Before release commits, compare the intended changed paths with `git diff --cached --name-only`. In sparse checkouts, stage tracked paths outside the sparse definition with `git add --sparse`, then confirm no intended changes remain unstaged.
